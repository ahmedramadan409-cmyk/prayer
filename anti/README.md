# تطبيق صلاتي مصر | Salaty Egypt 🇪🇬🕌

تطبيق إسلامي متكامل لمواقيت الصلاة والأذان في جمهورية مصر العربية، مبني باستخدام **Flutter & Dart**، مجاني بالكامل 100%، بدون أي إعلانات أو اشتراكات، يعمل بكفاءة تامة بدون إنترنت (Offline-First)، ويدعم منصتي **Android** و **iOS**.

---

## 🌟 أبرز مميزات التطبيق

1. **مواقيت الصلاة المعتمدة في مصر**:
   - مطابقة تامة لمعايير **الهيئة المصرية العامة للمساحة** (الفجر 19.5°، العشاء 17.5°، واحتياط الزوال والغروب).
   - قاعدة بيانات جغرافية شاملة لجميع محافظات مصر الـ 27 ومراكزها ومدنها والواحات.
   - العمل بدون إنترنت كلياً؛ يتم حساب المواقيت فلكياً بدقة داخل الجهاز.
   - دعم التوقيت الشتوي (UTC+2) والتوقيت الصيفي (UTC+3) والانتقال التلقائي بينهما وفق القانون المصري رقم 24 لسنة 2023.
   - إمكانية الضبط اليدوي للمواقيت بالدقائق (+/-) لتتوافق مع أي مسجد محلي.

2. **الأذان والتنبيهات المتقدمة**:
   - تنبيهات مجدولة دقيقة لكل صلاة على حدة.
   - خيارات صوتية متعددة: أذان القاهرة ومصر الكامل، أذان الفجر (مع الصلاة خير من النوم)، تكبيرات الأذان فقط، ونغمة تنبيه هادئة.
   - ميزة التنبيه المسبق قبل الأذان بعدد دقائق يحدده المستخدم (5، 10، 15، 20، 30 دقيقة).
   - معاينة حية للأصوات وإمكانية إيقاف صوت الأذان فوراً من داخل التطبيق أو من الإشعار.
   - التزام صارم بسياسات وأنظمة التشغيل (Android Exact Alarms وقيود أصوات iOS).

3. **اتجاه القبلة المشرفة بدقة فلكية**:
   - حساب اتجاه القبلة بالنسبة لموقع المستخدم باستخدام معادلات الدائرة العظمى (Great Circle Azimuth) للكعبة المشرفة بدقة عالية (21.4225° N, 39.8262° E).
   - بوصلة تفاعلية حية باستخدام مستشعر الهاتف المغناطيسي مع مؤشر ذهبي للكعبة.
   - عرض الزاوية بالدرجات والمسافة الجوية بالكيلومتر حتى مكة المكرمة.
   - وضع احتياطي في حال عدم توفر مستشعر البوصلة مع إرشادات المعايرة.

4. **التقويم الهجري والميلادي والمناسبات الإسلامية**:
   - عرض التاريخ الهجري والميلادي معاً.
   - تتبع المناسبات الإسلامية (رأس السنة الهجرية، عاشوراء، المولد النبوي، الإسراء والمعراج، رمضان، عيدي الفطر والأضحى).
   - إمكانية التعديل اليدوي للتقويم الهجري (-2 إلى +2 يوم) ليتطابق مع الرؤية الشرعية لدار الإفتاء المصرية.
   - استعراض مواقيت الشهر بالكامل مع إمكانية التنقل بين الشهور.

5. **تصميم احترافي وهوية بصرية إسلامية حديثة**:
   - ألوان الهوية: الأخضر الداكن الملكي `#0D472F`، الذهبي الهادئ `#D4AF37`، والأبيض.
   - دعم كامل للغة العربية واتجاه الكتابة من اليمين لليسار (RTL).
   - دعم الوضعين الليلي (Dark Mode) والنهاري (Light Mode).
   - واجهة مستخدم مريحة للاستخدام بيد واحدة (One-Handed Usability) وعداد تنازلي رقمي حي ومباشر حتى الصلاة القادمة.

6. **المجانية التامة وحماية الخصوصية**:
   - مجاني 100% لوجه الله تعالى.
   - بدون إعلانات، وبدون اشتراكات، وبدون طلب تسجيل حساب.
   - لا يتم جمع أو نقل أي بيانات شخصية أو موقع جغرافي؛ يعمل التطبيق بالكامل محلياً على جهاز المستخدم.

## 🏛️ بنية المشروع (Clean Architecture)

تم تنظيم المشروع بفصل طبقات المنطق والحساب عن طبقة واجهة المستخدم لسهولة الصيانة والتطوير:

```text
lib/
├── core/
│   ├── constants/            # الألوان، وثوابت المدن والمحافظات المصرية
│   │   ├── app_colors.dart
│   │   └── egypt_cities.dart
│   ├── theme/                # ثيمات التطبيق (الوضع النهاري والداكن)
│   │   └── app_theme.dart
│   ├── utils/                # المحركات الرياضية والفلكية
│   │   ├── prayer_calculation_engine.dart  # محرك الهيئة المصرية العامة للمساحة
│   │   ├── qibla_math.dart                 # حسابات القبلة والمسافة للكعبة
│   │   ├── hijri_date.dart                 # التقويم الهجري والمناسبات
│   │   └── time_formatter.dart             # تنسيق الأوقات (12h/24h)
│   └── services/             # الخدمات العامة
│       ├── storage_service.dart            # التخزين المحلي الدائم (SharedPreferences)
│       ├── audio_service.dart              # إدارة تشغيل ومعاينة الصوت ومنع التكرار
│       ├── notification_service.dart       # جدولة الإشعارات والمنبهات الدقيقة
│       └── location_service.dart           # التحقق من الموقع وتحديد أقرب محافظة
├── features/
│   ├── prayer_times/         # شاشة المواقيت الرئيسية
│   │   ├── models/           # مزودات الحالة (PrayerTimesProvider)
│   │   ├── repositories/     # مستودع البيانات (يدعم الحساب المحلي أو API مستقبلي)
│   │   ├── views/            # الشاشة الرئيسية (home_screen.dart)
│   │   └── widgets/          # بطاقة الصلاة القادمة وقائمة الصلوات الست
│   ├── qibla/                # شاشة اتجاه القبلة والبوصلة
│   ├── calendar/             # شاشة التقويم الهجري والميلادي
│   ├── settings/             # شاشات الإعدادات (المدن، الأذان، طريقة الحساب)
│   └── about/                # شاشة عن التطبيق والخصوصية وتراخيص الصوت
└── main.dart                 # نقطة الانطلاق وتهيئة الخدمات
```

## 🚀 متطلبات وخطوات التشغيل والبناء

### المتطلبات الأساسية
- تثبيت **Flutter SDK** (الإصدار 3.10.0 أو أحدث).
- **Android Studio** مع Android SDK Platform 34 لتطوير وبناء نظام أندرويد.
- **Xcode** (الإصدار 14 أو أحدث) مع جهاز Mac لبناء نظام iOS.

### خطوات التشغيل

1. **تثبيت الاعتماديات**:
   ```bash
   flutter pub get
   ```

2. **تشغيل الاختبارات التلقائية**:
   ```bash
   flutter test
   ```

3. **تشغيل التطبيق في وضع التطوير (Debug)**:
   ```bash
   flutter run
   ```

### خطوات بناء تطبيق Android (APK & App Bundle)

- لبناء ملف APK قابل للتثبيت المباشر:
  ```bash
  flutter build apk --release
  ```
  الملف الناتج يتواجد في: `build/app/outputs/flutter-apk/app-release.apk`.

- لبناء حزمة النشر لمتجر Google Play (AAB):
  ```bash
  flutter build appbundle --release
  ```
  الملف الناتج يتواجد في: `build/app/outputs/bundle/release/app-release.aab`.

### خطوات بناء تطبيق iOS

1. الانتقال إلى مجلد `ios` وتثبيت CocoaPods:
   ```bash
   cd ios
   pod install
   cd ..
   ```
2. بناء ملف IPA أو فتحه في Xcode:
   ```bash
   flutter build ipa --release
   ```
